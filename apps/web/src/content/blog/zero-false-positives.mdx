False alarms are the silent killer of on-call trust. When alerts fire for phantom network blips, engineers start muting notifications. Eventually, a real production outage slips through unnoticed because everyone assumed it was another false alarm.

We built SteadyStack's edge verification mesh to solve this directly: **four regions must independently agree on a failure before we ever page you**.

---

## Why Single-Probe Verification Fails

The standard approach used by legacy monitoring tools is a single-node check:

```
[Single Cloud Node in Virginia] ---- (ISP Routing Flap / Packet Loss) ----x----> [Your Server]
                                    |
                                    v
                           [Sends 3 AM False Alarm]
```

One poller server in one region issues an HTTP request. If that probe experiences local packet loss, DNS timeout, or socket contention, it assumes your server is down and triggers a page. Adding a sequential "retry in 30 seconds" helps only slightly if the same node hits the same local transit issue.

---

## SteadyStack's 4-of-7 Multi-Region Quorum Pipeline

SteadyStack takes a distributed consensus approach (2-of-3 quorum on the free tier, 4-of-7 on paid tiers). When edge probes execute their verification cycle across sovereign regions:

| Step                      | Action                                                                     | Execution Window |
| :------------------------ | :------------------------------------------------------------------------- | :--------------- |
| **1. Breadth**            | Every monitor is checked from all 7 sovereign regions every 60s            | Baseline cycle   |
| **2. Immediate Re-check** | A region seeing a failure triggers an immediate re-check to kill blips     | < 500ms          |
| **3. Quorum Vote**        | Durable Object Actor aggregates votes across all healthy probe regions     | < 800ms          |
| **4. Dispatch / Resolve** | Alert triggers only if at least 4 of 7 independent regions confirm failure | Immediate        |

If a transient ISP drop only affects Virginia (`enam`), the secondary probes in Frankfurt, London, Tokyo, and Singapore report `200 OK`. The transient blip is recorded as degraded regional noise, and your on-call engineer sleeps undisturbed.
