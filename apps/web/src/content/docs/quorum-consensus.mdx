The core architectural innovation in SteadyStack is **Quorum Consensus Verification**.

---

## The Problem with Legacy Monitors

Single-origin uptime monitors query your endpoints from one static IP or datacenter. When a Tier 1 telecom transit route experiences localized BGP flapping, high packet loss, or regional DDoS scrubbing, legacy tools assume your entire application is down and page your on-call engineers.

---

## How SteadyStack Solves This

When any edge probe node detects a non-2xx status code or a timeout, it does **not** immediately fire an alert. Instead, it submits the failure event to the **LatencyAggregator Durable Object**.

1. **Phase 1 (Probe Detection)**: A regional edge node records a connection failure or timeout.
2. **Phase 2 (Immediate Quorum Trigger)**: The central orchestrator triggers out-of-cycle partner node confirmations across independent regions.
3. **Phase 3 (Consensus Evaluation)**:
   - **Free Tier ("The Initiate")**: Requires **2 of 3 primary edge regions** to confirm the failure.
   - **Paid Tiers ("The Netrunner" / "The Construct")**: Requires **4 of 7 sovereign edge regions** (including out-of-band multi-ASN sentinel nodes) to confirm failure.
4. **Phase 4 (Dispatch)**: If consensus threshold is reached, incident routing rules execute and push notifications to PagerDuty, Slack, Discord, or Webhooks.
