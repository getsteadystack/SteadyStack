Most modern uptime providers host their checking infrastructure exclusively within a single cloud provider (such as AWS us-east-1). When AWS experiences an IAM or networking degradation, or when Cloudflare undergoes route maintenance, traditional tools fail simultaneously.

SteadyStack uses a **heterogeneous multi-cloud out-of-band topology**.

## The Out-of-Band Hetzner Sentinel Node

In addition to 6 high-density Cloudflare Worker edge nodes across North America, Europe, and Asia, SteadyStack operates an independent, dedicated bare-metal sentinel node hosted at Hetzner Online GmbH (Nuremberg, Germany).

- **Independent AS Routing**: Uses autonomous system `AS24940` (Hetzner) with multi-homed Tier 1 transit providers (Telia, NTT, Lumen).
- **Control Plane Verification**: If Cloudflare experiences a global edge control plane incident, the Hetzner sentinel continues executing checks and can autonomously dispatch SMS / PagerDuty alerts.
- **DNS Root Fallback**: Queries root TLD nameservers directly over raw UDP/TCP rather than relying on local recursive resolvers.
