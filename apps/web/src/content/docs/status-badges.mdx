SteadyStack provides edge-rendered, cache-optimized **SVG Status Badges** and embeddable widgets that update in real time with zero external JavaScript dependencies.

---

## 1. Markdown & HTML Embeds

Embed a live uptime badge into your GitHub README or project documentation:

### System Operational Badge

```markdown
[![Status](https://app.steadystack.dev/api/badge/acme-corp/status)](https://status.acmecorp.com)
```

### 30-Day Uptime Percentage Badge

```markdown
[![Uptime](https://app.steadystack.dev/api/badge/acme-corp/uptime)](https://status.acmecorp.com)
```

### Live Average Latency Badge

```markdown
[![Latency](https://app.steadystack.dev/api/badge/acme-corp/latency)](https://status.acmecorp.com)
```

## 2. Badge Customization Parameters

You can customize badge appearance via query parameters:

| Query Param | Values                                          | Default  | Description                    |
| :---------- | :---------------------------------------------- | :------- | :----------------------------- |
| `style`     | `flat`, `flat-square`, `for-the-badge`, `cyber` | `flat`   | Visual styling format          |
| `label`     | String                                          | `uptime` | Custom left-hand label text    |
| `color`     | Hex string (e.g. `23211a`, `ffd439`)            | Dynamic  | Custom right-hand accent color |
| `period`    | `7d`, `30d`, `90d`                              | `30d`    | Calculation lookback window    |

```html
<!-- Example custom styled badge -->
<img src="https://app.steadystack.dev/api/badge/acme-corp/uptime?style=for-the-badge&label=ACME+SLA" alt="Acme Uptime" />
```

## 3. JavaScript Micro-Widget

For web apps and client dashboards, embed an asynchronous status pill:

```html
<script
  src="https://app.steadystack.dev/widget.js"
  data-status-page="acme-corp"
  data-theme="auto"
  async>
</script>
<div id="steadystack-widget"></div>
```
